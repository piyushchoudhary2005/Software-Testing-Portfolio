# Screenshots to capture before submission
Take these on your own machine after running the commands in the main README, and save them here with these names:
1. `01_pytest_run.png`: output of `pytest -v` showing 71 passed.
2. `02_coverage_report.png`: terminal coverage or `06_Test_Reports/coverage_html/index.html` in a browser.
3. `03_mutation_run.png`: output of `python mutation_test.py`.
4. `04_defect_repro.png`: output of `python defect_repro.py`.
5. `05_github_commits.png`: the commit history page of your repository.

The `ui_*.png` files are already generated by `08_Web_UI_Testing/test_ui.py`; re-running the tests refreshes them.
